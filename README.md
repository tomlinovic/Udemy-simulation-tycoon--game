# Udemy Tycoon Game

2D farming and tycoon game developed in Unity using C#.

## Features
- Player movement and animations
- Inventory and toolbar system
- Farming and crop growth
- Tree chopping and resource gathering
- Trading system
- Crafting system
- Storage chests
- Day/night cycle
- Multiple scenes (Farm, House, Shop)

## Technologies
- Unity 2020.3.25f1
- C#
- Visual Studio

## About
This project was created as my final high school project for the course Advanced and Object-Oriented Programming. The game focuses on farming, resource management, crafting, and trading mechanics.
